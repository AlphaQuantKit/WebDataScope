# WebDataScope
WebDataScope是一个正在打造的Chrome/Edge插件。它可以让你在平台上方便的获得其数据分析报告

使用方法和功能详见使用教程

## Windows 一键更新

下载并解压发行版后，在已加载的插件目录中双击 `update.bat`。它会从本仓库的 GitHub 最新正式 Release 下载文件，在原目录完成更新；不需要安装 Git、Node.js 或 Python。

更新完成后，到 `chrome://extensions` 或 `edge://extensions` 找到 WorldQuant Scope，点一次“重新加载”，再刷新已打开的 WorldQuant 页面。

沿用原目录、保留已安装的扩展即可继续使用原来的配置、导入数据、缓存和共享 Key。请勿先删除扩展，也不要换目录重新安装。更新器会先校验压缩包和所需文件、备份待覆盖文件；覆盖失败时恢复旧文件，并报告错误。网络下载或校验失败时不会修改现有插件。

旧版目录没有更新器时，将新版中的 `update.bat` 和 `scripts/update-extension.ps1` 复制到原插件目录的对应位置即可。更新器只替换插件程序、图标、说明和更新器文件，保留自行放入的其他文件。

包含 `.git` 的目录也可以使用更新器。有 Git 时，仅检查本次更新会覆盖的文件，其他目录中的未提交修改不会阻止更新；没有 Git 时仍可更新，并保留恢复备份。更新器会记录上次更新的文件哈希，保护之后自行修改的文件。无需移动安装目录或删除 `.git`。
